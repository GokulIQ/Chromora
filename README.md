# Chromora HTML Template

Welcome to Chromora, the premium residential painting contractor HTML template.

## Quick Start
This template is built with standard HTML, CSS, and JS. No build tools are required to view the site. Simply open `index.html` in your browser.

## Features
- 27 Fully Responsive HTML Pages
- 2 Premium Homepages
- Unique Service & Blog Detail Pages
- Interactive Color Explorer
- Before/After Image Sliders
- Dark Mode Support
- RTL Compatible
- SEO Optimized
- Built on Bootstrap 5.3

For more details, see the `documentation/` folder.
